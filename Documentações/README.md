## 🚀 Como executar os projetos

1. Clone o repositório:

   ```bash
   git clone https://github.com/muriloo00/minhas-atividades-SENAI.git
   ```

2. Entre na pasta do projeto que deseja abrir:

   ```bash
   cd minhas-atividades-SENAI/SENAI-atividades/react-catalogo-componentes
   ```

3. Instale as dependências (projetos React):

   ```bash
   npm install
   ```

4. Inicie o projeto:

   ```bash
   npm run dev
   ```

   > Dependendo de como o projeto foi criado, o comando pode ser `npm start`. Confira o arquivo `package.json` da pasta.

Projetos que usam apenas HTML, CSS e JavaScript podem ser abertos direto no navegador, dando dois cliques no arquivo `index.html`.
